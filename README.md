🌴 Jungle Rush: The Lost Temple

🎮 About the Game

Jungle Rush: The Lost Temple is a 2D adventure game project set in a mysterious jungle. The player explores the jungle, faces challenges, and aims to reach the lost temple.

✨ Features

- 2D jungle adventure gameplay
- Multiple game scenes
- Main Menu
- Jungle Run
- Temple Level
- Game Over screen
- Victory screen
